# App Design Review - Implementation Templates

## Overview
This file contains templates for coding assistant prompts generated by the App Design Review skill. These templates are designed to work directly with your OnGarage project and integrate seamlessly with your existing development workflow.

## Prompt Template Structure

Each prompt follows this format:
```javascript
// Screen: [Screen name]
// Changes required: [List of fixes]
// Files to modify: [File paths]
// Note: Must be restructured, not rebuilt

1. [Fix description]
   - Change: [What to change]
   - Where: [Location]
   - Show: [What should be visible]
   - Constraint: [Style constraint]

2. [Next fix...]

// Ask for changed files and short change list
```

## Template Categories

### 1. SOS/Quotes Overlay Issues
**Common problems and fixes:**

```javascript
// Screen: 04 Option 1 v2, top (Home screen)
// Changes required: SOS overlay positioning and visibility
// Files to modify: /home/akila/Documents/Figcraft/ongarage-recommended-prototype.figcraft
// Note: Must restructure overlay position, not rebuild the screen

1. Fix SOS button affordance - Principle 005 Affordance: Button not accessible in low light
   - Change: Ensure SOS button has 44px minimum touch target and high contrast (4.5:1 ratio)
   - Where: SOS button layer in home screen frame
   - Show: Button with proper contrast and minimum touch area
   - Constraint: 44px minimum touch area, 4.5:1 contrast ratio

2. Fix SOS positioning - Principle 069 Fitts: Target not thumb-friendly
   - Change: Move SOS button to bottom-right corner within thumb reach
   - Where: Overlay position in home screen interactions
   - Show: Button positioned at bottom-right, accessible with one-handed use
   - Constraint: Within thumb reach when phone held normally

3. Fix SOS triggering - Principle 064 Feedback: Trigger unclear
   - Change: Update drag trigger to open SOS overlay on first scroll
   - Where: Home screen interaction panel, drag trigger
   - Show: SOS overlay opens with smooth animation after first scroll
   - Constraint: Trigger only after user interaction, not on page load

4. Fix Quotes accessibility - Principle 002 Accessibility: Not screen reader friendly
   - Change: Add ARIA labels and keyboard navigation to quotes button
   - Where: Quotes overlay frame and interaction
   - Show: ARIA labels, keyboard focus indicators, screen reader announcements
   - Constraint: WCAG 2.1 AA compliance for accessibility
```

### 2. Typography and Text Hierarchy
**Common problems and fixes:**

```javascript
// Screen: 04 Option 1 v2, top (Home screen)
// Changes required: Text hierarchy and typography improvements
// Files to modify: /home/akila/Documents/Figcraft/ongarage-recommended-prototype.figcraft
// Note: Restructure text layers, not rebuild typography system

1. Fix heading hierarchy - Principle 155 Recognition over Recall: Labels unclear
   - Change: Restructure heading levels (H1, H2, H3) for screen readers
   - Where: Text layers in home screen frame
   - Show: Semantic heading structure with proper hierarchy
   - Constraint: H1 for main page title, H2 for section headers

2. Fix button text clarity - Principle 153 Readability: Text hard to read
   - Change: Simplify button labels from Sinhala/English mix to consistent language
   - Where: Button text layers in various screens
   - Show: Clear, concise labels in single language (user preference)
   - Constraint: 13px minimum font size, 1.5 line height for readability

3. Fix typography scale - Principle 23 Typography hierarchy: Inconsistent sizing
   - Change: Apply consistent type scale (16px body, 24px heading, 20px subheading)
   - Where: All text layers across screens
   - Show: Scale maintains visual hierarchy and readability
   - Constraint: Type scale based on OnGarage design system

4. Fix line height - Principle 107 Legibility: Line spacing inadequate
   - Change: Increase line height to 1.5 for body text, 1.2 for headings
   - Where: Line height settings in typography styles
   - Show: Comfortable line spacing for easy reading
   - Constraint: 1.5 line height for body text, 1.2 for headings
```

### 3. Navigation and Interaction Patterns
**Common problems and fixes:**

```javascript
// Screen: 04 Option 1 v2, top (Home screen)
// Changes required: Navigation clarity and interaction patterns
// Files to modify: /home/akila/Documents/Figcraft/ongarage-recommended-prototype.figcraft
// Note: Restructure navigation, not rebuild interaction logic

1. Fix tab bar affordance - Principle 005 Affordance: Tab selection unclear
   - Change: Add visual feedback and clear affordance for tab selection
   - Where: Tab bar interaction in home screen
   - Show: Active state indicator, hover states, keyboard navigation
   - Constraint: 44px touch targets, clear visual feedback

2. Fix navigation mapping - Principle 113 Mapping: Path unclear
   - Change: Ensure navigation flows match user expectations
   - Where: Navigation interactions and transitions
   - Show: Clear navigation paths, breadcrumb trail
   - Constraint: Follow OnGarage navigation patterns

3. Fix action hierarchy - Principle 169 Priority: Important actions buried
   - Change: Restructure actions by importance (primary > secondary > tertiary)
   - Where: Action buttons and primary CTAs
   - Show: Clear action hierarchy with visual emphasis
   - Constraint: Primary actions most prominent, secondary less prominent

4. Fix feedback states - Principle 064 Feedback: No confirmation states
   - Change: Add appropriate feedback states for all interactions
   - Where: All interactive elements
   - Show: Hover, active, success, error states
   - Constraint: Micro-animations within 200ms, clear success confirmation
```

### 4. Layout and Spacing
**Common problems and fixes:**

```javascript
// Screen: 04 Option 1 v2, top (Home screen)
// Changes required: Layout and spacing improvements
// Files to modify: /home/akila/Documents/Figcraft/ongarage-recommended-prototype.figcraft
// Note: Adjust spacing, not rebuild layout structure

1. Fix content spacing - Principle 152 Proximity: Elements too close
   - Change: Add appropriate spacing between content elements
   - Where: Card margins, section padding, button margins
   - Show: Comfortable breathing space between elements
   - Constraint: 16px spacing between major elements, 8px between minor

2. Fix visual hierarchy - Principle 171 Similarity: Related elements not grouped
   - Change: Group related elements visually and spatially
   - Where: Card layouts, form fields, content sections
   - Show: Clear visual grouping with appropriate spacing
   - Constraint: Related elements within 8px, separated by clear boundaries

3. Fix touch target spacing - Principle 069 Fitts: Targets too close
   - Change: Ensure adequate spacing between touch targets
   - Where: Button groups, icon clusters, interactive element spacing
   - Show: Proper spacing allows easy target selection
   - Constraint: 8px minimum spacing between touch targets

4. Fix content hierarchy - Principle 091 Highlighting: Visual emphasis unclear
   - Change: Apply consistent visual hierarchy through spacing and emphasis
   - Where: Content sections, feature cards, call-to-action areas
   - Show: Clear content prioritization through layout
   - Constraint: Primary content most prominent, secondary less so
```

## Template Usage Guidelines

**SOS/Quotes Overlay Template:**
- Use when reviewing SOS/Quotes functionality
- Need accessibility fixes
- Require positioning improvements
- Adding touch target improvements

**Typography Template:**
- Use when reviewing text elements

- Use when reviewing user flows
